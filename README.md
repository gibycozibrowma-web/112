图片中的文字是越南语，这是一个注册页面的界面。以下是中文翻译：

顶部标签：

ĐĂNG NHẬP：登录

ĐĂNG KÝ：注册（当前选中的标签）

输入框（从上到下）：

Tài khoản：账号 / 用户名

Mật khẩu：密码

Mật khẩu xác nhận：确认密码

Mã giới thiệu：推荐码 / 邀请码

底部按钮：

ĐĂNG KÝ：注册


<img width="504" height="544" alt="image" src="https://github.com/user-attachments/assets/64ab5bef-a468-4841-9119-3ce29f7fc31c" />
Đổi mật khẩu：修改密码

Bật MK rút tiền：开启提现密码（注：MK 是 Mật khẩu 的缩写，这里指设置或开启提现时需要的密码）

Lịch sử：历史记录 / 历史

Luật chơi：游戏规则

Hoàn trả：返水 / 返还（注：在游戏/博彩平台语境下，通常指返还的金额或返利）

Đăng xuất：退出登录
